4. Territorio de naming — filtros vigentes

Tres ejes de exploración (validados implícitamente en la reunión): Sensación · Estatus · Material/detalle.

  • Luxury → campo sensorial/material (textura, mullido, bordado). Buen margen: ningún competidor real ocupa ese territorio.
  • Recliner → campo función/mecanismo/postura. Nunca relajación.

Exclusiones confirmadas:

  • "Riser" — fuera de toda comunicación externa (confundía a exhibidores).
  • Relajación / tranquilidad / "Zen" — el Recliner se mueve y vibra estando reclinado, no es una experiencia calma.
  • "Soft" — solo para uso interno / propuestas de venta, nunca como nombre de marca al consumidor.
  • "Ultra" y cualquier variante — coincide con el competidor 4DX.
