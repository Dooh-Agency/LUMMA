Viste que mencionás dos cosas relacionadas con el efecto M8: por un lado decís "Hoy en el mercado las salas son 4D E-Motion y Magnify 8", como si Magnify 8 fuera una línea con nombre propio que se promociona por sí sola. Nuestra lectura es esta: "Magnify 8" / "M8" es el nombre propio del efecto, que usan cuando quieren que sea protagonista (por ejemplo, promocionar una sala Magnify 8). Y "+" es un sufijo corto que usan cuando el efecto es un extra sobre otro modelo (Core, Luxury o Recliner), para no tener que repetir "Magnify 8" cada vez. ¿Es correcta esta lectura, o el "+" funciona distinto?
